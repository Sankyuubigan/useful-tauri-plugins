## Default Permission

Default permissions for the llama-engine plugin.

#### This default permission set includes the following:

- `allow-get-engine-status`
- `allow-install-llamacpp`
- `allow-set-engine-variant`
- `allow-check-engine-update`
- `allow-install-engine-update`
- `allow-remove-engine`
- `allow-set-engine-dir`
- `allow-get-models-catalog`
- `allow-get-engine-config`
- `allow-get-auto-download-info`
- `allow-auto-download-default-model`
- `allow-add-model`
- `allow-remove-model`
- `allow-delete-model-file`
- `allow-get-mmproj-path`
- `allow-ensure-mmproj`
- `allow-get-model-capabilities`
- `allow-get-all-capabilities`
- `allow-estimate-prompt-memory`
- `allow-get-model-params`
- `allow-set-model-params`
- `allow-reset-model-params`
- `allow-download-model`
