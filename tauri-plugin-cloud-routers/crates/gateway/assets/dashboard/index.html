Модели ниже получены реальным запросом GET /models к провайдеру. Они и есть список, который видят IDE: пустой список означает, что провайдер не будет использоваться в чате.
Релей — Edge-функция на Vercel. Она нужна, когда провайдер недоступен из вашей сети (региональная блокировка или фильтрация трафика). Запросы выходят с территории Vercel.

Развернуть автоматически

Нужен Vercel Access Token (vercel.com/account/tokens). Шлюз задеплоит воркер сам и подставит URL автоматически.

Развернуть вручную

Надёжный путь, если авто-деплой недоступен. Скопируйте исходник воркера, создайте на Vercel Edge-проект, задайте переменные окружения RELAY_TOKEN (обязательно — нажмите «Показать секрет», чтобы скопировать его здесь) и, по желанию, ALLOWED_HOSTS (список хостов через запятую), затем вставьте выданный адрес ниже.

Маршрутизация через релей

Для каждого провайдера галочка «через релей» в карточке на вкладке «Провайдеры».
