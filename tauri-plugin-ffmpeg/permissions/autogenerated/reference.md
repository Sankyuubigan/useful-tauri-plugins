## Default Permission

Default permissions for the ffmpeg plugin.

#### This default permission set includes the following:

- `allow-ffmpeg-status`

## Permission Table

<table>
<tr>
<th>Identifier</th>
<th>Description</th>
</tr>


<tr>
<td>

`ffmpeg:allow-ffmpeg-status`

</td>
<td>

Enables the ffmpeg_status command without any pre-configured scope.

</td>
</tr>

<tr>
<td>

`ffmpeg:deny-ffmpeg-status`

</td>
<td>

Denies the ffmpeg_status command without any pre-configured scope.

</td>
</tr>

<tr>
<td>

`ffmpeg:allow-ffmpeg-status`

</td>
<td>

Allow reading FFmpeg status (installed, versions, dir).

</td>
</tr>
</table>
