## Default Permission

Default permissions for the image-engine plugin.

#### This default permission set includes the following:

- `allow-get-image-engine-status`
- `allow-install-image-engine`
- `allow-set-image-engine-variant`
- `allow-check-image-engine-update`
- `allow-install-image-engine-update`
- `allow-remove-image-engine`
- `allow-set-image-engine-dir`
- `allow-get-image-models-catalog`
- `allow-get-image-bundle-info`
- `allow-set-selected-image-bundle`
- `allow-download-image-bundle`
- `allow-validate-image-bundle-dir`
- `allow-set-image-bundle-dir`
- `allow-remove-image-bundle`
- `allow-remove-image-bundle-from-list`
- `allow-get-image-pool-orphans`
- `allow-remove-image-pool-orphans`
- `allow-estimate-image-memory`
- `allow-generate-image`
- `allow-edit-image`
- `allow-get-video-bundles`
- `allow-get-video-bundle-info`
- `allow-set-selected-video-bundle`
- `allow-validate-video-bundle-dir`
- `allow-set-video-bundle-dir`
- `allow-download-video-bundle`
- `allow-remove-video-bundle-files`
- `allow-generate-video`
- `allow-list-remote-loras`
- `allow-download-remote-lora`
