## Default Permission

Default permissions for the speech plugin (CrispASR TTS/STT engine).

#### This default permission set includes the following:

- `allow-tts-speak`
- `allow-tts-presets`
- `allow-tts-capabilities`
- `allow-tts-unload`
- `allow-tts-save-wav`
- `allow-tts-download-engine`
- `allow-tts-download-model`
- `allow-tts-engine-backends`
- `allow-tts-list-models`
- `allow-tts-list-voices`
- `allow-tts-add-voice`
- `allow-tts-delete-voice`
- `allow-tts-update-voice`
- `allow-tts-voice-avatar`
- `allow-tts-voice-audio`
- `allow-tts-voice-trimmed-audio`
- `allow-tts-check-update`
- `allow-tts-default-dirs`
- `allow-tts-get-settings`
- `allow-tts-save-settings`
- `allow-stt-get-settings`
- `allow-stt-save-settings`
- `allow-stt-start`
- `allow-stt-stop`
- `allow-stt-get-status`
- `allow-stt-inject-text`
