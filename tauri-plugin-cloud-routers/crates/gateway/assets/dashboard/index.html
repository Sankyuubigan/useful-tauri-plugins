Мои релеи

Активный релей обслуживает провайдеров с галочкой «через релей». Остальные хранятся напоследок — включаются кнопкой «Сделать активным». Секрет RELAY_TOKEN общий для всех релеев.

Развернуть автоматически

Vercel: Access Token (vercel.com/account/tokens). Cloudflare: API-токен с правом «Workers Scripts: Edit» (dash.cloudflare.com → My Profile → API Tokens). Шлюз сам загрузит воркер, поставит секрет RELAY_TOKEN и подставит URL.

Развернуть вручную

Ручной путь ниже — про Vercel (для Cloudflare проще авто-деплой выше). Надёжный, если авто-деплой недоступен. Скопируйте исходник воркера, создайте на Vercel Edge-проект, задайте переменные окружения RELAY_TOKEN (обязательно — нажмите «Показать секрет», чтобы скопировать его здесь) и, по желанию, ALLOWED_HOSTS (список хостов через запятую), затем вставьте выданный адрес ниже.

Маршрутизация через релей

Для каждого провайдера галочка «через релей» в карточке на вкладке «Провайдеры».
